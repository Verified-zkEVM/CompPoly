# Curated benchmark group set, with two consumers:
#
#   * the correctness gate in .github/workflows/lean_action_ci.yml, which runs
#     `CompPolyBench --validate-only` over these groups on every PR;
#   * the default selection of .github/workflows/benchmarks.yml, the on-demand
#     timing workflow.
#
# Deliberately a subset. `lake exe CompPolyBench --list` shows every registered
# group; a new group is covered here only once added below, and an unknown key
# fails the run, so a renamed group is caught rather than silently dropped.
#
# Excluded on purpose are the groups whose single iteration costs seconds
# (univariate-batch-large-*, univariate-mod-by-monic-medium-*), and the sizes
# of a sweep that the middle of the sweep already covers: one size of the
# multiplicative NTT and two of the schoolbook/NTT crossover stand in for the
# rest, since a body that is wrong at one size is wrong at all of them.
#
